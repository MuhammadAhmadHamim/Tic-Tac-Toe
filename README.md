## ◈ Why This Repository Exists

This is not the most complex project in this profile. It is not the biggest, not the most feature-rich, not the most technically impressive.

It is the **first**. 

Before the C++ vault. Before the OOP blueprint. Before the SQL intelligence and the DSA grind. Before the Hospital Management System. Before any of it — there was this: a 3x3 grid, two players, and a C compiler. This is where the lore began.

---

## ◈ What It Does

A fully playable **two-player Tic-Tac-Toe game** built in C, running entirely in the terminal. Player 1 is X. Player 2 is O. They take turns, the board updates after every move, and the game knows when someone has won — or when nobody has.

Simple. Clean. Complete.

---

## ◈ Features

```
✓  Two-player mode           →  Player 1 (X) vs Player 2 (O)
✓  Input validation          →  Invalid and out-of-range moves are rejected
✓  Live board display        →  The grid updates and prints after every move
✓  Win detection             →  All rows, columns, and diagonals are checked
✓  Draw detection            →  Recognises a full board with no winner
```

---

## ◈ The Board

```
  Col:  0   1   2

Row 0:  X | O | X
       -----------
Row 1:  O | X |  
       -----------
Row 2:    | O | X   ← Player 1 wins
```

Players enter a **row** and **column** number (0, 1, or 2) to place their mark. The board redraws. The game checks. Life goes on — or ends in victory.

---

## ◈ Gameplay Flow

```
1.  Game launches → Empty 3x3 board is displayed
2.  Player 1 (X) enters row and column → Mark placed
3.  Board redraws → Win/draw checked
4.  Player 2 (O) takes their turn → Same process
5.  First to get three in a row wins
6.  If all 9 cells fill with no winner → Draw declared
```

## ◈ What Was Built Here

| Concept | How It Appears |
|---|---|
| **2D Arrays** | The 3x3 board is a `char grid[3][3]` |
| **Loops** | Game loop runs until win or draw |

| **Input Validation** | Out-of-range and already-taken cells are rejected |

| **User Interaction** | `scanf` reads player input each turn |
